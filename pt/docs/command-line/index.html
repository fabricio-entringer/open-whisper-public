    Bloco 09 Linha de comando

    Leitura · 6 min

    Transcreva um arquivo ou um vídeo pelo terminal com open-whisper transcribe, em texto, legendas ou JSON.

    Neste bloco

    1. Para que serve
    2. Ter o comando à mão
    3. Receitas
    4. O que sai e para onde
    5. A rede
    6. Tempo e interrupção

    O open-whisper transcribe faz o que a janela de vídeo faz, só que pelo terminal: você passa um arquivo ou um link do YouTube, e ele imprime a transcrição. Serve para scripts, ou para quem transcreve com frequência e prefere digitar. Esta página mostra os usos do dia a dia; a Referência do comando traz todas as opções e todos os códigos de saída.

    Para que serve

    • Transformar uma gravação em texto ou legendas sem abrir janela nenhuma.
    • Entregar uma transcrição a outro programa, em JSON, com o tempo de cada frase e, se você pedir, de cada palavra.
    • Repetir a mesma transcrição com as mesmas opções.

    O comando faz parte do app: não há mais nada para instalar. Ele usa os seus ajustes (a Velocidade e o Modelo da janela de vídeo, e o Idioma) como ponto de partida, e nunca muda nenhum deles. Ele nunca grava arquivo, e o ditado continua funcionando enquanto ele roda.

    Ter o comando à mão

    Mac

    Se você instalou pelo Homebrew, o open-whisper já está no PATH. Se instalou pelo .dmg, crie um link uma vez. Num Mac com Apple Silicon:

    > ln -s "/Applications/Open Whisper.app/Contents/MacOS/open-whisper" /opt/homebrew/bin/open-whisper

    Num Mac com Intel, o link vai em /usr/local/bin/open-whisper. Confira no Terminal:

    > open-whisper --version

    Ele imprime open-whisper seguido da versão. Sem argumentos, o open-whisper abre o app da barra de menus.

    Windows

    O instalador coloca a pasta do Open Whisper no PATH do seu usuário. Depois de instalar, abra uma janela nova do Prompt de Comando ou do PowerShell (uma que já estava aberta não enxerga a mudança) e confira:

    > open-whisper --version

    Ele imprime open-whisper seguido da versão. O open-whisper roda o open-whisper.com, a versão de console do app, então o terminal espera por ele e mostra a saída. Sem argumentos, ele termina com erro de uso: o app em si abre pelo menu Iniciar.

    Se o seu PATH já era muito longo, o instalador não mexe nele. Nesse caso, rode o comando pelo caminho completo: o open-whisper.com na pasta onde o Open Whisper foi instalado, normalmente %LOCALAPPDATA%\Open Whisper.

    Ponha entre aspas um caminho que tem espaços. Um caminho relativo é lido a partir da pasta em que o terminal está.

    Receitas

    1. Um arquivo em texto

    > open-whisper transcribe aula.mov > aula.txt

    O texto é o mesmo que o Copiar da janela de vídeo dá com Texto: um cabeçalho curto e depois a transcrição. Qualquer arquivo que a janela de vídeo aceita também funciona aqui; veja Vídeo e arquivos.

    2. Legendas

    > open-whisper transcribe aula.mov --format srt > aula.srt
> open-whisper transcribe aula.mov --format vtt > aula.vtt

    Os arquivos são os mesmos que o Salvar da janela grava.

    3. JSON para outro programa

    > open-whisper transcribe aula.mov --format json > aula.json

    O texto inteiro fica em transcript.text, cada frase com início e fim em transcript.segments, e os ajustes usados em settings. Campos novos podem aparecer com o tempo; os que existem mantêm o nome.

    4. O tempo de cada palavra

    > open-whisper transcribe aula.mov --format json --words > aula.json

    Cada segmento ganha uma lista words, com o início, o fim e uma confiança de 0 a 1 para cada palavra. Serve para cortar pausas ou começos em falso no meio de uma frase. Só funciona com --format json e só numa transcrição feita neste dispositivo: legendas não têm o tempo das palavras.

    5. Números como foram falados

    > open-whisper transcribe narracao.wav --numbers spoken --format json > narracao.json

    Por padrão, o motor escreve os números em algarismos ("310"). Com --numbers spoken, ele escreve por extenso, como foram ditos, e nenhum algarismo aparece em lugar nenhum. É útil para conferir uma narração contra o roteiro. Um número romano é feito de letras e pode ficar como está, e perto de um número o motor às vezes enfia uma palavrinha a mais. Só vale neste dispositivo, não para legendas.

    6. Nomes que ele erra

    > open-whisper transcribe aula.mov --prompt "Fabricio, Entringer, DevOps" > aula.txt

    O --prompt passa ao motor a grafia de nomes e jargões, só nesta chamada. Liste as palavras; não escreva uma frase. O nome de um arquivo nunca influencia a transcrição dele, então este é o único jeito de dar uma dica para um arquivo.

    7. Fixar o idioma

    > open-whisper transcribe aula.mov --lang pt > aula.txt

    Fixar o idioma falado na gravação acerta mais do que a detecção automática. --lang auto detecta. Os códigos são os dos 16 idiomas dos Ajustes: pt, en, es, fr, de, it, nl, ru, zh, ja, ko, ar, hi, pl, tr, uk. Qualquer outro código é erro de uso.

    8. Um link do YouTube

    > open-whisper transcribe "https://www.youtube.com/watch?v=ID_DO_VIDEO" > video.txt
> open-whisper transcribe "https://www.youtube.com/watch?v=ID_DO_VIDEO" --on-device > video.txt

    Ponha o link entre aspas. Sem --on-device, o comando usa as legendas do vídeo quando há legendas utilizáveis, e leva segundos. Com --on-device, ele baixa o áudio e transcreve no computador; essa opção é o seu consentimento, como a escolha na janela. Um vídeo sem legendas utilizáveis e sem --on-device termina com o código de saída 7. Links precisam do yt-dlp, como na janela de vídeo.

    9. Outro modelo ou outra velocidade

    > open-whisper transcribe aula.mov --model medium-q5_0 --quality accurate > aula.txt

    O modelo precisa já estar no computador: o comando nunca baixa um modelo e termina com o código de saída 4 se ele falta. Baixe pelos ajustes ou pela janela de vídeo (Modelos). --model small-q5_1, o modelo embutido, sempre funciona.

    O que sai e para onde

    • O resultado vai para a saída padrão, e mais nada: completo, e então o comando termina com o código 0. Em qualquer falha, ela fica vazia, então meia transcrição nunca chega ao seu arquivo.
    • Todo o resto vai para a saída de erro: as linhas de progresso que começam com open-whisper:, o motivo em uma linha quando algo falha, e as mensagens do próprio motor. O texto dela pode mudar, e dá para descartá-la sem perder nada.

    Leia o resultado só quando o código for 0. Para ver o código do último comando:

    Mac

    > echo $?

    Windows

    No Prompt de Comando, echo %ERRORLEVEL%. No PowerShell, $LASTEXITCODE.

    Cada código tem o seu significado (4 é modelo que falta, 5 é formato não suportado, 7 é vídeo que precisa de --on-device…). A tabela completa, com o que fazer em cada caso, está na Referência do comando.

    A rede

    • Um arquivo do seu computador não usa rede nenhuma.
    • Um link do YouTube usa a rede só para buscar o vídeo. Antes de buscar qualquer coisa, o comando avisa na saída de erro: open-whisper: buscando o vídeo na rede — a transcrição em si continua nesta máquina.

    Tempo e interrupção

    Num Mac com Apple Silicon e o modelo embutido, uma hora de áudio leva cerca de três minutos; a primeira chamada ainda gasta um ou dois segundos carregando o modelo. Um link com legendas utilizáveis volta em segundos.

    Para interromper, aperte CtrlC. O comando termina em cerca de dois segundos, com o código 130, e não entrega nada.

    Nota

    O comando faz uma entrada por chamada: nada de pastas, listas ou playlists. Para transcrever muitos arquivos, rode uma vez por arquivo, num laço do seu shell.
