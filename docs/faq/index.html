    Appendix A1 Frequently asked questions

    Reading time · 3 min

    Short answers to what people ask first: price, the internet, languages, Windows and Mac, the shortcut.

    In this block

    1. Price and account
    2. Privacy and the internet
    3. Windows and Mac

    Short answers, each pointing to the page that covers the topic in full.

    Price and account

    Is it really free?

    Yes. Open Whisper is free to install and use, for personal or professional work, on as many computers as you like. There is no subscription and no trial. The terms of use say so in writing.

    Does it need an account?

    No. There is no account, no sign-up and no API key. You install it and use it.

    Privacy and the internet

    Does my voice leave the computer?

    No. The audio stays in memory while you dictate, is transcribed on your computer and is then discarded. It is never written to disk and never sent anywhere. You can check it with a network monitor: see Privacy.

    Does it work offline?

    Yes. Dictation never uses the internet. Only two optional things do: downloading a larger model, and transcribing a YouTube link. Transcribing a video file from your computer works offline too. See Privacy.

    Windows and Mac

    Why does Windows warn about the installer?

    The first Windows installer isn't signed yet, so Windows shows Windows protected your PC. Check the file's hash, then click More info and Run anyway. The steps are in Install.

    When is the Mac version coming?

    The Mac version ships once Apple has signed and notarized it. It will install with Homebrew or a .dmg. There is no date: follow the Releases page to hear when it's out.

    Using it

    Which languages does it understand?

    By default it detects the language you speak, each time you dictate, so you can switch languages between dictations. You can also pin one of 16 languages in Settings for better results. The app's own screens are in English or Portuguese, following your system's language.

    Can I change the shortcut?

    Yes, during setup or in Settings. The default is ⇧⌘Space on the Mac and CtrlShiftSpace on Windows. A shortcut needs a modifier, such as ⌘ or Ctrl. All keys are in Shortcuts and keys.

    Does it work in any app?

    It pastes wherever a normal paste works: browsers, editors, chat apps, documents. When it can't paste (a password field, or a window opened as administrator on Windows), the text stays on the clipboard and you paste it yourself. Nothing is lost. See Where the text lands.

    What doesn't it do?

    It writes down what you say, where your cursor is. It doesn't rewrite your text with AI, record meetings, translate, or keep a history. The full list, with the reason for each, is in What Open Whisper doesn't do.
