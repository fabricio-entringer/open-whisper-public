    Block 01 Install

    Reading time · 4 min

    What your computer needs, and how to download, check and install Open Whisper on Windows and, once it ships, on the Mac.

    In this block

    1. Where to get it
    2. What your computer needs
    3. Install on Windows
    4. Install on the Mac
    5. Update to a new version
    6. Uninstall

    Open Whisper is free and needs no account. This page says what your computer needs, how to download and check the installer, how to install it, and how to move to a new version.

    Where to get it

    Every version is published on the Releases page, with a .sha256 file next to each download so you can check it. The site, openwhisper.entringer.dev, links to the same files.

    Note

    The first release is for Windows. The Mac version ships once Apple has signed and notarized it. It will install with Homebrew or a .dmg, as described below.

    PlatformDownloadChecksum file
    WindowsOpen.Whisper_X.Y.Z_x64-setup.exeOpen.Whisper_X.Y.Z_x64-setup.exe.sha256
    MacNot yet: it ships once Apple has signed it—

    X.Y.Z is the version number. Get Open Whisper only from that page or, once the Mac version ships, from Homebrew: those are the official channels.

    What your computer needs

    WindowsMac
    SystemWindows 10 (22H2) or Windows 11, 64-bitmacOS 14 Sonoma or later
    ProcessorIntel or AMD with AVX2 (Intel from 2013, AMD from 2015)Apple Silicon or Intel, one download for both
    Disk spaceUnder 300 MBAbout 200 MB
    InternetOnly during installation, if WebView2 is missingNot needed once downloaded
    AccountNoneNone

    On a Windows PC with an ARM processor, Open Whisper runs under emulation, not natively. On Windows, transcription runs on the processor; it does not use the graphics card.

    Install on Windows

    1. On the Releases page, download Open.Whisper_X.Y.Z_x64-setup.exe and the .sha256 file next to it.
    2. Check the download (below): it tells you the file is the one that was published.
    3. Open the installer.
    4. If Windows shows Windows protected your PC, choose More info, then Run anyway.
    5. Follow the installer. It installs for your user only and never asks for an administrator password. It picks English or Portuguese on its own, and shows the terms of use.
    6. Start Open Whisper from the Start menu if it is not running yet. Its icon appears in the notification area, next to the clock, and the setup window opens: see First run.

    Check the download

    Open Command Prompt or PowerShell in the folder where you saved the installer, and run:

    > certutil -hashfile Open.Whisper_X.Y.Z_x64-setup.exe SHA256

    Open the .sha256 file in Notepad. The long string of letters and digits that certutil prints must be the same as the one in that file. If it is not, delete the installer and download it again from the Releases page.

    Why Windows warns you

    The first Windows release is not signed with a code-signing certificate yet, and SmartScreen warns before it runs an installer that is not signed. Checking the hash is how you confirm the file is the one published.

    WebView2

    Open Whisper's windows are drawn by Microsoft Edge WebView2. If it is missing from your PC, the installer downloads and installs it by itself, without asking. That is the only moment the installation needs the internet.

    The open-whisper command

    The installer also puts the open-whisper command on your user PATH, for the command line. Open a new Command Prompt or PowerShell window after installing: windows that were already open do not see it.

    > open-whisper --version
open-whisper X.Y.Z

    If the command is not found

    If your user PATH was already very long, the installer leaves it untouched so it cannot damage it. Run the command by its full path instead: open-whisper.com, in the folder where Open Whisper was installed.

    Install on the Mac

    With Homebrew

    > brew install --cask fabricio-entringer/tap/open-whisper

    This installs Open Whisper in Applications and puts the open-whisper command on your PATH.

    With the .dmg

    1. On the Releases page, download Open.Whisper_X.Y.Z_universal.dmg and the .sha256 file next to it, into the same folder.
    2. Check the download. In Terminal, in that folder, run:
      shasum -a 256 -c Open.Whisper_X.Y.Z_universal.dmg.sha256
      It must answer OK. If it does not, delete the .dmg and download it again.
    3. Open the .dmg and drag Open Whisper into the Applications folder.
    4. Open Open Whisper from Applications. Its icon appears in the menu bar and the setup window opens: see First run.

    Caution

    Keep the app directly in Applications (or in the Applications folder inside your home folder). Opened from the .dmg, from Downloads or from a subfolder, it cannot turn on Open at login.

    Installed from the .dmg, the open-whisper command is not on your PATH yet: Command line shows the one-line link that puts it there.

    Signed and notarized

    The Mac version is signed with an Apple Developer ID and notarized by Apple, so macOS can confirm who made it and that it was not changed. It is not in the Mac App Store: pasting into other apps needs the Accessibility permission, and the App Store's sandbox does not allow it.

    Update to a new version

    Open Whisper does not check for updates and never goes online to look for them. New versions appear on the Releases page; you can follow them with its feed, https://github.com/fabricio-entringer/open-whisper-public/releases.atom.

    Mac

    • With Homebrew: run brew upgrade --cask open-whisper.
    • With the .dmg: quit Open Whisper from its menu, download and check the new .dmg, and drag the app into Applications again, replacing the old one.

    Windows

    1. Quit Open Whisper from its menu.
    2. Download and check the new installer.
    3. Run it the same way. Your settings and downloaded models are kept.

    Uninstall
