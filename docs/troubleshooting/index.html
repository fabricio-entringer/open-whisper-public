    Block 11 Troubleshooting

    Reading time · 9 min

    Every known problem, by what you see: the cause and the steps that fix it, on Mac and Windows.

    In this block

    Find what you see, read why it happens, and follow the steps. The problems are grouped by moment: installing, permissions, the shortcut, recording, the paste, video and the command line.

    Installing

    "Windows protected your PC"

    The installer isn't signed yet, so SmartScreen doesn't recognise it. The warning is expected.

    1. Check the file first: in the folder where you downloaded it, run certutil -hashfile Open.Whisper_X.Y.Z_x64-setup.exe SHA256 (with your version's file name).
    2. Compare the result with the hash in the .sha256 file from the same release. They must match.
    3. Open the installer again and click More info, then Run anyway.

    The installer needs the internet

    If Windows lacks WebView2, the installer downloads it during installation. Connect to the internet and run the installer again. Open Whisper itself doesn't need the internet afterwards.

    Your processor is older

    On Windows, Open Whisper needs a processor with AVX2 (Intel from 2013, AMD from 2015). An older processor is not supported.

    The app doesn't seem to open

    Open Whisper has no window and no Dock or taskbar button. It lives in one icon.

    Mac

    Look in the menu bar, near the clock. Click the icon to open the menu.

    Windows

    Look in the notification area, next to the clock. If you don't see it, click ^ (show hidden icons) and drag the Open Whisper icon onto the taskbar.

    Starting the app a second time does nothing visible: the copy that is already running stays in charge.

    "Open at login" can't be turned on

    Mac

    The message Move Open Whisper to the Applications folder to use this option. means the app is running from somewhere else: the .dmg, Downloads, or a subfolder.

    1. Quit Open Whisper.
    2. Move Open Whisper.app directly into /Applications (not into a subfolder such as Utilities).
    3. Open it from there and turn the option on again.

    If it says Approve Open Whisper in System Settings → Login Items., click Open System Settings and switch Open Whisper on under Login Items.

    Windows

    The message Install Open Whisper with its installer to use this option. means this copy isn't the one the installer put on your PC. Install it with the installer and open that copy.

    If it says Turned off in Windows Settings → Apps → Startup., the option was switched off in Windows. Turn it on again in Open Whisper, or click Open Windows Settings and switch it on under Startup.

    Permissions

    Microphone access is off

    Mac

    Dictation needs the microphone. If you refused it, or setup says Microphone access is off:

    1. Open System Settings → Privacy & Security → Microphone.
    2. Switch Open Whisper on.
    3. Dictate again.

    Windows

    Windows lets apps use the microphone unless it was turned off in its settings. When it is off, Open Whisper doesn't record and says so: Windows is blocking the microphone. Allow it in Settings → Privacy & security → Microphone, including for desktop apps. Open Whisper's Settings show the same line at the top of Recording, with the key Open Windows Settings.

    1. Open Settings → Privacy & security → Microphone.
    2. Turn on microphone access at the top of the page, and Let desktop apps access your microphone.
    3. Dictate again.

    Auto-paste won't turn on (Mac)

    Mac

    macOS applies the Accessibility permission only when the app opens again. If the switch in System Settings is on but the text still goes to the clipboard:

    1. Quit Open Whisper from its menu (Quit Open Whisper) and open it again. During setup, Reopen Open Whisper does this for you.
    2. If the switch keeps flipping back off, make sure you're using the copy from the official download.
    3. Still stuck? Clear the permission in Terminal and grant it again:
      tccutil reset Accessibility dev.entringer.openwhisper
    4. Choose Enable auto-paste… in the menu, switch Open Whisper on, and reopen the app.

    Windows

    There is no Accessibility permission on Windows: auto-paste is always available. If the text isn't pasted, see The text was not pasted.

    The shortcut

    Pressing the shortcut does nothing

    1. Open the menu and look at Start Recording: the key shown beside it is the shortcut that is really active.
    2. If another app already uses your combination, Settings says … could not be registered. Pick another combination in Settings.
    3. Until then, Start Recording in the menu always works.
    4. If the shortcut works but nothing is pasted, see Recording and The text was not pasted.

    "… is reserved by macOS" or "… is reserved by Windows"

    The system keeps that combination for itself. While it is chosen, Open Whisper uses ⇧⌘D on the Mac or CtrlShiftD on Windows instead.

    1. In Settings, click Change and press another combination.
    2. Or click Keep and use the fallback shown beside Start Recording in the menu.

    The full list of reserved combinations is in Shortcuts and keys.

    The recorder doesn't accept the combination

    A shortcut needs a modifier. A key on its own, even a function key such as F5, can't be the shortcut.

    Mac

    Include ⌘, ⌃ or ⌥. Shift alone doesn't count. If you see Could not save preferences, the combination has no modifier: press it again with one.

    Windows

    Include Ctrl or Alt. Shift alone doesn't count, and the Windows key can't be part of the shortcut. If you see Could not save preferences, the combination has no modifier: press it again with one.

    The shortcut gets in the way of another app

    On Windows, CtrlShiftSpace also means something in Word and VS Code. Choose another combination in Settings, such as CtrlAltSpace.

    Esc doesn't cancel

    Esc cancels only while Open Whisper says Recording. Once it says Transcribing, the recording is over and Esc no longer cancels.

    Mac

    In Hold to Talk, press Esc while you still hold the shortcut. Both work: Esc alone, or the held keys plus Esc. If your shortcut holds both ⌥ and ⌘, ⌥⌘Esc belongs to macOS (Force Quit): use Toggle mode to cancel with Esc.

    Windows

    In Hold to Talk with CtrlShiftSpace, Esc can't cancel: CtrlShiftEsc opens Task Manager. Either:

    1. Release the keys: the recording ends and is transcribed as usual.
    2. Switch to Toggle mode, where Esc cancels.
    3. Or choose a shortcut such as CtrlAltSpace, which cancels with CtrlAltEsc.

    Recording

    "Microphone unavailable — check the permission or whether another app is using it."

    No microphone was found, or another app is holding it.

    1. Check that a microphone is connected and selected in the system's sound settings.
    2. Close the app that is using it (a call, a recorder) and try again.
    3. If that isn't it, check the permission (see Permissions).

    "Nothing was recorded — check the microphone permission, or hold the shortcut a moment longer."

    The press was too short to capture any audio, or the microphone gave nothing.

    1. Hold the shortcut, start speaking, and release only after the last word.
    2. If it keeps happening, check the permission (see Permissions).

    Nothing happens after you speak

    When no speech was heard, nothing is pasted and there is no notice, only the closing sound. Speak a little closer to the microphone and try again. On Windows, also check that the microphone isn't blocked (see Permissions).

    The recording stopped by itself

    Two settings can end a recording:

    • Max recording: at the limit (120 seconds by default) the recording stops and what was captured is transcribed. A notice says Recording stopped at the time limit — transcribing what was captured. Raise it up to 1800 seconds in Settings, under Advanced.
    • Stop after silence (Toggle mode only): after you've spoken, that much silence ends the recording. Raise the time or turn it off in Advanced. A phrase spoken very quietly at the very end can be left out.

    "Couldn't load the speech model. Check Settings."

    The model you chose is missing or damaged.

    1. Open Settings and expand Advanced.
    2. Under Model, choose Default (the bundled one).
    3. If that fails too, reinstall Open Whisper.

    "Download failed. The current model is still in use."

    The model didn't download. The previous one keeps working.

    1. Check your internet connection.
    2. Choose the model again in Advanced → Model to retry. A download can't start during a dictation.

    Words come out wrong, or in the wrong language

    In Settings, set Language to the language you speak instead of Auto-detect. Larger models make fewer mistakes, in exchange for a download and more time: see Models.

    The text was not pasted

    A notice says "Copied to clipboard"

    The text couldn't be pasted where you were, so it was kept on the clipboard. Nothing was lost.

    Mac

    It happens when auto-paste is off (Settings shows Automatic paste: off), in a password field, or when nothing you can type in has focus (the desktop, a Finder window, a page you're only reading).

    1. Click where the text should go.
    2. Press ⌘V, or choose Retry Last Transcription in the menu.
    3. To paste automatically from now on, click Turn on… in Settings, or Enable auto-paste… in the menu.

    Windows

    It happens in a window opened as administrator (Windows doesn't let other apps type into it), in a password field, or when nothing you can type in has focus.

    1. Click where the text should go.
    2. Press CtrlV, or choose Retry Last Transcription in the menu.

    Running Open Whisper itself as administrator is not recommended.

    The text appeared nowhere

    In browsers and apps built on them (Chrome, VS Code, Slack, Discord), Open Whisper can't always tell whether a text field has focus, so it pastes anyway. If no field had focus, the paste lands nowhere and the clipboard goes back to what it held before.

    1. Click in the field.
    2. Choose Copy Last Transcription in the menu, then paste. The last dictation is kept until you quit.

    Dictations don't show in Windows clipboard history

    This is on purpose. Dictated text never goes into WinV or cloud clipboard sync, even when it stays on the clipboard. See Privacy.

    What you had copied didn't come back

    After a paste, Open Whisper puts back what the clipboard held, but only text. An image or other content you had copied may not come back.

    Video

    "Open Whisper needs yt-dlp to reach videos"

    Video links need yt-dlp, a free tool you install yourself. Open Whisper never installs or updates it. Files on your computer don't need it.

    Mac

    > brew install yt-dlp

    If it says the installed yt-dlp is too old (2025.01.01 is the minimum):

    > brew upgrade yt-dlp

    Windows

    > winget install yt-dlp.yt-dlp

    If it says the installed yt-dlp is too old (2025.01.01 is the minimum):

    > winget upgrade yt-dlp.yt-dlp

    If yt-dlp is installed somewhere Open Whisper doesn't look, set the OPEN_WHISPER_YT_DLP environment variable to its full path.

    "It failed for a reason Open Whisper does not recognize"

    YouTube changes often, and an older yt-dlp stops working. Update yt-dlp (above) and try again.

    "That is not a YouTube video link"

    Only links to a single YouTube video work. Playlists, channels and other sites are refused. Open the video itself and copy its link.

    "This video has no usable captions"

    Click Transcribe on this device. It downloads the audio and transcribes it on your computer, which takes a few minutes.

    "YouTube is rate-limiting requests right now" or "No internet connection."

    Wait a few minutes, check your connection, and try again.

    "Open Whisper cannot decode this file's audio"

    The file uses a format the app can't read (Opus, AC-3, E-AC-3, DTS, or an AVI, WMV or ASF file). Export it as MP4 or M4A with AAC, or as MP3, FLAC or WAV, and try again.

    "This video is longer than the 3-hour limit"

    Videos and files over 3 hours don't fit safely in memory. Cut the recording into parts under 3 hours.

    "Open Whisper transcribes one video at a time"

    Wait for the current job or cancel it. Copy is also refused while you dictate: wait for the dictation to finish and click it again.

    The video comes out in the language you used before

    If you changed Language in Settings and a video still comes out in the old one, quit Open Whisper and open it again.

    Quitting asks about a video

    A video transcription is still running. Quitting now will lose it. Click Keep running to let it finish, or Quit anyway to lose it.

    Command line

    "open-whisper" is not found

    Mac

    If you installed with Homebrew, the command is already on your PATH. If you installed from the .dmg, link it once:

    > ln -s "/Applications/Open Whisper.app/Contents/MacOS/open-whisper" /opt/homebrew/bin/open-whisper

    On an Intel Mac, use /usr/local/bin/open-whisper as the last part.

    Windows

    1. Open a new terminal window: windows that were open during the installation don't see the command yet.
    2. If it still isn't found, your PATH was too long for the installer to add it. Run open-whisper.com by its full path, in the folder where Open Whisper is installed.

    Running open-whisper with no arguments stops with a usage error on purpose: the app itself starts from the Start menu.

    Exit status 2

    The command was mistyped: an unknown option or value, a missing input, two inputs, or an input given without transcribe. Run open-whisper --help and check the command.

    Exit status 4

    The model isn't downloaded, and the command never downloads anything. Add --model small-q5_1 to use the bundled one, or download the model in the app first.

    Exit status 7

    The video has no usable captions. Run it again with --on-device to transcribe the audio on your computer.

    Every exit status, with what to do, is in the Command reference.
